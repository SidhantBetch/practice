# Problem 1: Smart Vehicle Number Analyzer (Array)
Story:

TVS manufactures smart vehicles with unique identification numbers. The quality team wants to analyze a list of vehicle numbers and find the second largest unique number.

### Input:
    N = 7
    arr = [10, 20, 5, 20, 30, 15, 30]

### Output:
    20
#### Explanation:

    Largest = 30
    Second largest unique = 20

## Constraints:
- 2 ≤ N ≤ 10⁵
- -10⁹ ≤ arr[i] ≤ 10⁹

# solution
```python
N = int(input())
arr = []
for i in range(N):
    arr.append(int(input()))

fmax_val = -float('inf')
smax_val = -float('inf')
for i in range(N):
    if fmax_val < arr[i]:
        smax_val = fmax_val
        fmax_val = arr[i]
    elif smax_val < arr[i] and arr[i] != fmax_val:
        smax_val = arr[i]


print(smax_val)
```
