# Problem 2: Fuel Efficiency Pattern (Sliding Window)
## Story:

A TVS electric scooter records its battery efficiency every hour. Find the maximum average efficiency for a continuous period of K hours.

### Input:
    Efficiency = [5,8,3,9,2,6,7]
    K = 3
### Output:
    6.0
#### Explanation:

    Windows:
    
    5+8+3 =16
    8+3+9 =20
    3+9+2 =14
    9+2+6 =17
    2+6+7 =15
    
    Maximum average = 20/3 = 6.67

# Solution
```python
N = int(input("N: "))

Efficiency = []
for i in range(N):
    Efficiency.append(int(input("Value: ")))

k = int(input("K: "))

maxavg = float("-inf")

for i in range(len(Efficiency) - k + 1):
    Total = 0
    for j in range(k):
        Total += Efficiency[i + j]
    maxavg = max(maxavg, Total / k)

print(maxavg)
```
